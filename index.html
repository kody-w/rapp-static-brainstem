More: how setup is checked

Your AI follows this page's setup contract: it tells you what it will install and waits for your yes, checks the download's SHA-256 against the contract, installs one skill folder (moving any older copy aside, never deleting it), then proves it with a real tool run. Before any tool runs, the runner checks its SHA-256 fingerprint against the published list. That shows the file wasn't damaged or changed. It doesn't show the code is safe, so only use brainstems from people you trust. The tools run on the AI's own machine or sandbox, with your permissions.

Check that it really ran

Ask your AI: Use my rapp-static-brainstem skill to run the Probe agent with the word pineapple-42. It replies with a fingerprint of your word. Type the same word here. If the codes match, real code ran. The AI couldn't have guessed it.

For AI agents reading this page

The person wants their static RAPP Brainstem. Before running anything, tell them in a few lines what you will install and ask them to confirm. It is one skill folder: SKILL.md, run.py and single-file agents, with no server and no packages. It is not the live RAPP Brainstem on localhost, so don't look for one.

GitHub Copilot and Claude Code

Follow rapp-static-operator.json (read the raw JSON, not a summary). Download bundle/rapp-static-brainstem.zip from this page's own folder, check its SHA-256 against the contract, and unzip it into ~/.copilot/skills/rapp-static-brainstem/ (GitHub Copilot) or ~/.claude/skills/rapp-static-brainstem/ (Claude Code), moving any existing copy aside. Then prove it: run python3 run.py call Probe - with {"nonce": "<a new random word>"} on stdin, and show the person the word and its fingerprint.

Any other AI that runs Python

Read SKILL.md and follow it for this conversation. Run tools only through run.py, which checks each tool's SHA-256 first, and show real output, never an imagined run. If you can't open links, ask the person to attach bundle/SKILL.md, which carries everything in one file.
