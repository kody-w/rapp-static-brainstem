When to reach for it.

Your AI does the thinking. The brainstem does the fixed steps, and names the version that did them.

Use the brainstem when
  • A job has to be done the same way every time, like a check your team repeats.
  • You need to show how you got the answer.
  • The same tool has to work in more than one AI.
Just ask your AI when
  • It's about your mail, meetings, calendar or files.
  • It's writing, research or a judgment call.
  • It needs the internet, or no tool here does the job.

Tested: we gave Copilot Cowork two versions of a contract with seven small edits buried in them. Plain Cowork found all seven, and so did the brainstem's CompareDocuments tool. The difference is that the brainstem named the exact tool version that did the work, and it works the same way every time.

More: how it's checked

Before any tool runs, the runner checks its SHA-256 fingerprint against the published list. That shows the file wasn't damaged or changed. It doesn't show the code is safe, so only use brainstems from people you trust. The tools run on the AI's own machine or sandbox, with your permissions.

  • Dashboard: re-checks every fingerprint in your browser
  • SKILL.md, registry.json, llms.txt
  • Source · Releases

Check that it really ran

Ask your AI: Use my rapp-static-brainstem skill to run the Probe agent with the word pineapple-42. It replies with a fingerprint of your word. Type the same word here. If the codes match, real code ran. The AI couldn't have guessed it.

For AI agents reading this page

The person wants to use this static brainstem. Read SKILL.md and follow it. Run tools only through run.py, which checks each tool's SHA-256 before it runs. Show real output, never an imagined run. This needs no server and no installs beyond Python 3.10 or later. It is not the live RAPP Brainstem on localhost, so don't look for one. If you can't open links, ask the person to attach bundle/SKILL.md, which carries everything in one file.
